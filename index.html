How I use AI coding agents

Claude Code in an IDE · ~20 sessions on one TypeScript / React project · patterns, not a single task

Agent runs the commands, repo config holds the rules, and every ticket follows the same loop. I steer with short prompts; the standards live in files, not in my head.
~90%of tool calls are shell commands (git, CI, package, data CLIs), not edits
1 loopverify → review → ship → CI follow-up, every time
Every chatstarts with the same token-saving skill

Recurring session types

Ticket delivery

Paste a ticket id and a one-line goal (dependency bump, framework migration, bug report). Agent does the change, changeset, squash, push.

Triage and decide

Hand over a pile of client error logs or UI bug reports. Agent clusters them and proposes fix or silence per item.

Data and tooling

Generate varied test data, visualize resource relationships, check library versions and prices. Throwaway scripts stay out of the repo.

Meta questions

Token cost per call, available models, running several agents in one repo safely.

The loop

Implement→ Lint / types / tests→ Self-review (simplify + bugs)→ Changeset→ Squash & push→ Wait for CI and bots→ Fix what applies (max 3 rounds)

Patterns that make it work

Rules as files

AGENTS.md with ten critical rules, plus .claude/rules/ for coding and testing standards.

Load context on demand

Knowledge base split by topic; the agent pulls only what the task needs.

Skills for repeat jobs

Pre-PR gate, release readiness, data investigations, report generation.

Memory

Decisions and audit findings persist between sessions, so I don't re-explain them.

Ask, don't guess

Agent asks me only for real decisions (e.g. missing ticket id before naming a branch).

Mistakes become rules

A repeated error leads to a proposed rules-file diff that I approve.
